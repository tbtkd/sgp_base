# Prompt de continuidad

Trabaja sobre la versión 1.6.1 del Sistema de Expediente Clínico. Conserva el diseño visual actual y la compatibilidad de datos. Usa `app/db.py` para persistencia/respaldos/migraciones verificables, `app/core/validators.py` para toda entrada y `AuditLog.record()` para eventos críticos. Mantén los roles `admin`, `medico`, `recepcion`, separados de los perfiles `medico_general`, `dentista`, `nutricion`; recepción nunca accede a contenido clínico. Sólo Nutrición puede capturar o importar antropometría. La nota clínica y la receta ordinaria son documentos distintos. Sólo Medicina/Odontología con cédula y domicilio completos puede emitir una receta. Los folios emitidos son inmutables: las correcciones crean sustituciones trazables y los documentos adicionales conservan folio independiente. No se admiten medicamentos sujetos a receta especial y toda impresión requiere revisión/firma autógrafa. Los cambios de contraseña invalidan sesiones y ninguna credencial llega a logs o auditoría. La identidad de cuenta vive en el top bar: el compacto usa `username` y el menú rotula por separado nombre, rol, área y cédula; el sidebar es de navegación y `logo.png` es la marca canónica. El modal de citas inicia cerrado; las pestañas clínicas y las vistas de impresión deben funcionar sin recursos CDN. No incluyas bases, secretos, logs, respaldos, cachés o entornos virtuales en la entrega.
